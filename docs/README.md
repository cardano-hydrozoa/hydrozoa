# Hydrozoa documentation

Two sections:

- **[user-guide/](user-guide/README.md)** — task-oriented how-tos: deploying a head, building deposits
  and L2 transactions, minting on L2. Start here if you want to *use* a head.
- **[spec/](spec/README.md)** — design and reference docs for the protocol and the codebase
  (consensus cycles, the L2 isomorphism, persistence, API endpoints, style guide). Start here if you
  want to understand *how it works* or contribute.

The how-tos link into `spec/` for the underlying design rather than repeating it.
